# 異界オークション — YEP2026 MVMNT

展示会場のカメラが、来場者の持ち物を予告なく撮影し、架空の都市のオークションに強制出品します。住人たちが勝手に入札し、落札証明書が出ます。

## 体験の流れ（すべて自動）
1. ページを開くとカメラが起動し、画面左に監視カメラとして常時表示
2. 8〜28秒のランダムな間隔で、3秒の「照準ロック」予告のあと勝手にシャッター
3. 撮った画像がそのまま、6つの世界（無人島サバイバル／忍者の里／ゾンビがあふれた世界／怪獣が毎週来る街／巨大ロボットがある世界／江戸時代）に「強制出品」され、住人3人が1件ずつ入札 → 落札
4. 落札証明書を14秒表示し、下の「落札記録」に追加。次の都市で監視を再開

## ファイル
| ファイル | 内容 |
|---|---|
| `index.html` | 会場モニター用の画面（16:9想定） |
| `config.js` | GASのURL、撮影間隔、QRのURL |
| `gas/Code.gs` | Claude APIの中継（APIキーはここに隠す） |

## セットアップ
未来救出局（minato_timetravel_postalworker）と同じ手順です。
1. スプレッドシートを作り、「拡張機能 > Apps Script」に `gas/Code.gs` を貼る
2. スクリプト プロパティに `ANTHROPIC_API_KEY` を設定（任意：`MODEL`、`RATE_PER_MIN`、`SAVE_IMAGES`）
3. `setupCheck` を実行して許可 → 「ウェブアプリ」として公開（実行：自分／アクセス：全員）
4. 発行されたURLを `config.js` の `GAS_URL` に貼り、GitHub Pagesで公開

`GAS_URL` が空のときは「模擬鑑定」で動きます（写真の中身は読まず、用意した台本で競売）。

## 会場での操作
- 最初に一度だけ画面をクリック（ブラウザの仕様で、操作後でないと音が鳴らないため）
- `F`：全画面　`Space`：今すぐ撮影（デモ用）　`G`：落札グリッドの表示切り替え
- 落札グリッド：最新9件を、写真・落札額・落札者（英語名）・MVMNTロゴつきで3×3に並べる。同じPCの別ウィンドウで `index.html?grid` を開くと、グリッドだけを2台目のモニターに出せる（落札のたびに自動で更新）
- カメラは HTTPS か localhost でしか動きません。ローカル確認は `npx serve .` などで

## プライバシー
- 画面に「このカメラの前にある物は、予告なく出品されます」と常に表示
- 人物は鑑定しないようプロンプトで指示。写真は既定で保存しない（`SAVE_IMAGES=true` で保存）
- 会場入口にも撮影の告知を掲示してください
